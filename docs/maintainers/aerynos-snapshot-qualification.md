only for `opengl-next` context creation. It forwards ordinary renderer creation.
The shim is removed afterwards and is not distributed in the package. This
exercises the actual packaged fallback without modifying the engine or settings.

The synthetic two-second 4K BL/1080p EL fixture is generated by
`tools/dv-engine/generate_synthetic_p7.py` and repeated ten times with MP4Box.
Probe validation confirms 480 frames, Profile 7 and BL/EL/RPU present. This is
routing and visible-playback evidence, not physical Dolby Vision output or
reference FEL picture accuracy. Software rendering/decoding in llvmpipe is
expected. Physical GPU/HDR output, NPU inference and Plex/Emby accounts remain
unqualified. Fontconfig configuration-version and optional Canberra warnings
remain recorded; tested text and video render.
