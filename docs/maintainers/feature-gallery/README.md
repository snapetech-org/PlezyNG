# Feature gallery

Eighteen dark-mode views rendered from production components. Select images in the main README for full resolution. `manifest.json` records source revision, component hashes, renderer and fixture state.

Regenerate with `tools/store-assets/feature_reader_capture_test.dart` followed by `feature_capture_test.dart`; both require `PLEAZYNG_FEATURE_OUTPUT`. See the store asset tooling README for commands.
