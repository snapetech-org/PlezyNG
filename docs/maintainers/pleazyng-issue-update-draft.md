We've now implemented the Pleazyng rebrand in the app source: display names and localized copy, native package identities, media/OAuth links, release filenames and package recipes. SnapeTech is identified as publisher and maintainer.

We've also replaced the NG-lettered ribbon with the new symbol, typeset the exact Pleazyng wordmark, regenerated platform and alternate-icon artwork, removed the inherited README showcase and old-name store screenshot bases, and updated our website source and artwork. New builds no longer register plezy://; the canonical media scheme is pleazyng://. Upstream attribution and GPL notices remain.

The repository name is intentionally unchanged for now, so existing source links remain valid.

This is source implementation, not a claim that every channel has shipped. Signed platform builds, existing-user data/purchase migration, fresh store screenshots, provider registrations, domain cutover and store/package submissions still need verification.
