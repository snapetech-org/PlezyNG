# Authenticated visualizer catalog

The default app catalog is published by this repository's `visualizer-catalog.yml` workflow on `main`. GitHub issues a short-lived OIDC identity; official Cosign 3.1.4 signs the exact `MilkRust.catalog.v1\\n`-prefixed payload and verifies it before publication. No private signing key is committed or supplied through a build variable. The upstream MilkRust Ed25519 root remains unprovisioned; this does not claim upstream key custody.

The app pins the Fulcio intermediate, Rekor v1 public key, exact workflow identity, OIDC issuer, immutable repository ID and immutable owner ID. These pins are reviewed source, derived from Sigstore's immutable root-signing revision `f22ebe7cea5352c2c3b675aa211f730e279c7b78`. The verifier accepts only the publisher's v0.3 message-signature profile, verifies the certificate signature, identity/usage restrictions, payload signature, signed log timestamp, and certificate validity at that authenticated time. It rejects alternative roots, algorithms, DSSE, public-key-only bundles and mixed envelopes. It relies on Rekor's signed entry timestamp; it does not claim to implement general Sigstore CT/SCT or Merkle-checkpoint verification.

Catalog expiry, monotonic sequence, rollback checkpoints, revocations, license clearance, sample-fixture identity, qualification metadata, archive digests, download limits and explicit user-triggered refresh remain enforced. Keyless schema 2 and explicitly configured Ed25519 schema 1 have separate trust checks. A failed signature never enables downloads.

The authentic public fixture in `test/fixtures/visualizer/authenticated-catalog.json` is mandatory in ordinary tests. Dedicated CI also retrieves the actual published catalog at an immutable repository commit. It tests authentic signatures, altered payloads, certificates, algorithms, log IDs, timestamps/indexes, missing transparency promises, public-key downgrades and client metadata admission. The weekly publisher renews the 14-day catalog; an expired catalog fails closed while already installed presets remain usable.
