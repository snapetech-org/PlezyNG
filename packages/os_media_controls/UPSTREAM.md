# Media controls source

Vendored from [edde746/media_controls](https://github.com/edde746/media_controls/tree/a27208e641790029ac54d825b97508575caee1a7), commit a27208e641790029ac54d825b97508575caee1a7, by [@edde746](https://github.com/edde746) and its credited contributors. The original LICENSE is retained. This is the exact dependency revision previously used by Pleazyng.

Pleazyng additions expose the existing Android session to a browsable music service and add music media-ID commands. There remains one media session and one playback owner. This local copy preserves the existing Apple, Windows and Linux implementations.
